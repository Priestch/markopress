# Welcome to MarkoPress Test Site

This is a test project using MarkoPress with a **custom content directory**.

## Features

- Custom content location: `my-content/` instead of default `content/`
- Pages, docs, and blog all working from custom directories
- Full markdown support with syntax highlighting
- Theme customization options
