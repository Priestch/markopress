## Become a Contributor

Want to join the team? We welcome contributions of all kinds:

### Ways to Contribute

**Code**
- Fix bugs and implement features
- Build plugins and themes
- Improve performance
- Add tests

**Documentation**
- Write guides and tutorials
- Improve existing docs
- Translate documentation
- Create examples

**Design**
- Design new themes
- Improve UI/UX
- Create illustrations
- Build design systems

**Community**
- Help others on Discord
- Answer questions on GitHub
- Write blog posts
- Share your projects

**Outreach**
- Give talks and presentations
- Write about MarkoPress
- Share on social media
- Organize meetups

### Get Started

1. **Join the Community**
   - [Discord](https://discord.gg/markopress)
   - [GitHub Discussions](https://github.com/markopress/markopress/discussions)

2. **Find an Issue**
   - [Good First Issues](https://github.com/markopress/markopress/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
   - [Help Wanted](https://github.com/markopress/markopress/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22)

3. **Read the Contributing Guide**
   - [CONTRIBUTING.md](https://github.com/markopress/markopress/blob/main/CONTRIBUTING.md)

4. **Make Your First Contribution**
   - Fork the repository
   - Create a branch
   - Make your changes
   - Submit a pull request
