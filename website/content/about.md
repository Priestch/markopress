# About MarkoPress

MarkoPress is a general-purpose static site generator built on top of Marko.js v6, designed to be compatible with VitePress and Docusaurus content.

## Why MarkoPress?

- Uses the powerful Marko.js templating engine
- Full TypeScript support
- Plugin-based architecture
- Fast development with Vite
- Static site generation for optimal performance

## Architecture

Built on top of @marko/run with:
- Markdown processing via gray-matter and markdown-it
- File-based routing
- Plugin system with lifecycle hooks
- Theme system with slot-based overrides
