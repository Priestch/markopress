# Welcome to MarkoPress

MarkoPress is a modern static site generator that combines the simplicity of Markdown-based content with the power of Marko.js components.

## Features

- **Markdown + Frontmatter** - Write content in Markdown with YAML frontmatter
- **File-based Routing** - Auto-generate routes from your content structure
- **Plugin System** - Extend functionality with a powerful plugin architecture
- **Theme System** - Customize your site with slot-based theme overrides
- **VitePress Compatible** - Use existing VitePress content with minimal changes
- **Docusaurus Compatible** - Migrate from Docusaurus with ease

## Getting Started

Create your first markdown file in `content/pages/` and start writing!

```js
console.log('Hello, MarkoPress!');
```
